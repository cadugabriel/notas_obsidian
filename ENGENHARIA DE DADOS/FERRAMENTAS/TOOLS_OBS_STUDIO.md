# 📹 Produção de Vídeo & Configuração do OBS Studio

Referência rápida de resoluções para criação de conteúdo e diretórios estruturais para gerenciamento do OBS Studio.

---

## 1. Padrões de Resolução de Vídeo

| Resolução (Pixels) | Proporção (Aspect Ratio) | Tipo de Conteúdo / Destino                         |
| :----------------- | :----------------------- | :------------------------------------------------- |
| **1080 x 1920**    | 9:16 (Vertical)          | **Vídeos Curtos** (Shorts, Reels, TikTok)          |
| **1920 x 1080**    | 16:9 (Horizontal)        | **Vídeos Normais** / Tradicionais (YouTube, Aulas) |

---

## 2. 🔌 Plugins do OBS Studio

> 📁 **Diretório de Instalação (Windows):** Para adicionar, remover ou gerenciar plugins manualmente no OBS Studio, os arquivos de extensão devem ser armazenados exatamente no seguinte caminho do sistema:

```text
C:\ProgramData\obs-studio\plugins
```

_Nota: A pasta `ProgramData` é oculta por padrão no Windows. Caso não a encontre, ative a opção "Itens ocultos" na aba Visualizar do Explorador de Arquivos._

# 📝 Nano

Referência prática de atalhos do teclado para navegação, edição e salvamento de arquivos via terminal Linux/Unix utilizando o editor de texto Nano.

---
## 1. Atalhos Essenciais e Operações de Arquivo

| Atalho     | Ação Executada        | Uso Prático                                                                          |
| :--------- | :-------------------- | :----------------------------------------------------------------------------------- |
| `Ctrl + G` | **Abre Ajuda / Help** | Exibe a documentação interna com a lista completa de comandos.                       |
| `Ctrl + O` | **Salva o arquivo**   | Grava as alterações atuais feitas no arquivo (pede confirmação de nome).             |
| `Ctrl + R` | **Ler arquivo**       | Insere o conteúdo de outro arquivo externo na posição atual do cursor.               |
| `Ctrl + X` | **Sair do editor**    | Fecha o arquivo atual. Se houver alterações não salvas, perguntará se deseja salvar. |


## 2. Edição e Manipulação de Texto

| Atalho     | Ação Executada           | Uso Prático                                                                                  |
| :--------- | :----------------------- | :------------------------------------------------------------------------------------------- |
| `Ctrl + K` | **Recorta Texto**        | Corta a linha inteira onde o cursor está posicionado e a envia para a área de transferência. |
| `Ctrl + U` | **Cola Texto**           | Cola o conteúdo da linha que foi recortada anteriormente no local do cursor.                 |
| `Ctrl + J` | **Justifica o texto**    | Ajusta o parágrafo ou a linha atual dentro das margens padrão do editor.                     |
| `Ctrl + T` | **Checagem Ortográfica** | Executa o corretor ortográfico (necessita de pacotes/plugins extras instalados).             |
 

## 3. Localização e Navegação

| Atalho     | Ação Executada       | Uso Prático                                                                              |
| :--------- | :------------------- | :--------------------------------------------------------------------------------------- |
| `Ctrl + W` | **Localizar texto**  | Abre o mecanismo de busca (Where Is) para procurar palavras ou termos no arquivo.        |
| `Ctrl + Y` | **Página Anterior**  | Move a visualização do arquivo uma tela para cima (Page Up).                             |
| `Ctrl + V` | **Página Posterior** | Move a visualização do arquivo uma tela para baixo (Page Down).                          |
| `Ctrl + C` | **Posição Atual**    | Mostra na barra inferior o número exato da linha, coluna e caractere onde o cursor está. |

# 💻 Visual Studio Code

Referência rápida de comandos do teclado para edição multilinha e formatação de estruturas de dados no VS Code.

---

## 1. Edição e Formatação Avançada

| Atalho                 | Ação Executada                 | Uso Prático                                                                              |
| :--------------------- | :----------------------------- | :--------------------------------------------------------------------------------------- |
| `Ctrl + Alt + ↑` / `↓` | **Seleção Múltipla de Linhas** | Cria múltiplos cursores verticalmente para editar várias linhas simultaneamente.         |
| `Shift + Alt + Enter`  | **Formatar JSON**              | Alinha, indenta e embeleza (*prettify*) estruturas de arquivos JSON de forma automática. |

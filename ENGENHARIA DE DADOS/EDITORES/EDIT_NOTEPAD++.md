# 📝 Notepad++

Referência rápida de comandos do teclado para conversão de caixa (maiúsculas e minúsculas) em textos selecionados no Notepad++.

---

## 1. Conversão de Caixa (Maiúsculas / Minúsculas)
 
| Atalho                            | Ação Executada          | Resultado Esperado                                                           |
| :-------------------------------- | :---------------------- | :--------------------------------------------------------------------------- |
| `Ctrl + Shift + U`                | **Coloca em MAIÚSCULA** | Transforma todos os caracteres selecionados em letras maiúsculas.            |
| `Ctrl + U`                        | **Coloca em minúscula** | Transforma todos os caracteres selecionados em letras minúsculas.            |
| `Alt + U` <br>ou `Ctrl + Alt + U` | **Capitaliza Palavras** | Coloca em maiúscula apenas o primeiro caractere de cada palavra selecionada. |

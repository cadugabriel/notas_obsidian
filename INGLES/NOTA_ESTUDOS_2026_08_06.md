# Notas gerais

- O inglês é modular, ou seja, é como se cada pedaço de uma frase pudesse ser substituído ou acrescentado por outro pedaço, ou seja, a estrutura é quase sempre a mesma, o que muda são os verbos, pessoas, lugares, qualidades, etc.
-  Quando usa DID ou DIDN'T o verbo não é conjugado;
- Exceto para o verbo TO BE, qualquer outro verbo a estrutura para perguntar se você fez algo é sempre a mesma "DID YOU <VERBO> <LUGAR/COISA>"

# PREPOSIÇÕES

 - for: para o(a). Exemplo: I work for Sensedia
 - on: a(os). Exemplo: I work on Saturday
 - in: em/no(s). Exemplo: I work in São Paulo

# VERBOS

## REGULARES

- A maioria ganha a terminação `"ed"`, `"d"` ou `"ied"` quando colocados no passado.
	Exemplo:
		- I play   basketball on   weekends. = PRESENTE
		- I played basketball last weekend.  = PASSADO

| **PRESENT** | **PAST** |
| ----------- | -------- |
| like        | liked    |
| work        | worked   |
| play        | played   |
| study       | studied  |
| use         | used     |
| watch       | watched  |

- A conjugação no passado simples é a mesma para todos os pronomes.

### VERB LIKE

- Significa Gostar;
- Quem gosta, gosta de alguma coisa, no caso "THE ...". Exemplos: "I like the cake. I didn't like the music.".
- Exemplos:
I like = Eu gosto                     | I liked          = Eu gostei
I don't like = Eu não gosto    | I didn't like  = Eu não  
Do you like ? = Você gosta   | Did you like  = Você gostou ?


---

## IRREGULARES

Não tem explicação, apenas são assim.

| **PRESENT** | **PAST** |
| ----------- | -------- |
| go          | went     |
| buy         | bought   |
| make        | made     |
| write       | wrote    |
| run         | ran      |
### VERB GO

- Significa Ir;
- "I go to the....", exceto quando é escola, aí é "I go to school". Idem para o verbo work, não tem "the".

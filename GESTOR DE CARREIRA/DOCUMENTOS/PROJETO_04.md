# INFORMAÇÕES

## Nome do Projeto

Modernização de Plataforma de Dados

## Período

2019-2021

## Segmento

Corporativo

## Contexto

Reestruturação de ambiente híbrido contendo mais de 30 servidores e mais de 500 bancos de dados.

## Principais Atividades

- **Arquitetura de Dados:** Desenho e implementação da nova arquitetura analítica na nuvem (Azure) separando workloads transacionais e analíticos.
    
- **Assessment & Discovery:** Levantamento do ambiente legado, mapeamento de volumetria, rotinas e dependências dos 500+ bancos de dados.
    
- **Planejamento e Migração para Cloud:** Consolidação da infraestrutura e migração estruturada de workloads para a nuvem.
    
- **Engenharia de Transformação com dbt:** Estruturação da camada de transformação de dados e modelagem analítica com dbt, garantindo testes automatizados, documentação modular, linhagem de dados e boas práticas de controle de versão (Git).

## Tecnologias

- SQL Server
- Azure
- DBT
- T-SQL
- GIT

## Resultados

- Economia aproximada de R$ 600 mil no primeiro ano.
- Consolidação da infraestrutura analítica.

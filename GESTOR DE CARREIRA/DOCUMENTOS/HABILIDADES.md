# OBJETIVO

Esse documento centraliza todas as competências técnicas e profissionais comprovadas do candidato.

Este documento constitui a única fonte oficial para identificação das competências do candidato.

As evidências de utilização de cada competência permanecem registradas nos documentos de experiencias e projetos.

---

# REGRAS

- Registrar apenas competências comprovadas.
- Cada competência deverá aparecer apenas uma vez.
- Nunca incluir tecnologias sem evidência na Base de Conhecimento.
- Organizar as competências por categoria.
- Não registrar níveis de conhecimento.
- Não registrar tecnologias em estudo.
- Sempre que uma nova experiência ou projeto for incorporado, revisar este documento.
